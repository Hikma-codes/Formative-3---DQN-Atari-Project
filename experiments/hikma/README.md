# Hikma's DQN Hyperparameter Experiments

This folder contains evidence from Hikma's ten DQN hyperparameter
experiments on Gymnasium ALE Q*bert-v5.

## Experiments

- 10 distinct hyperparameter configurations.
- 100,000 training steps per experiment.
- Training performed using Google Colab with a Tesla T4 GPU.
- 10 evaluation episodes per trained model.
- 100 evaluation episodes in total.

## Folder structure

- configs/: Experiment configurations.
- results/: Training results, evaluation results, report and
  individual experiment records.
- plots/: Training and evaluation comparison visualizations.

## Model checkpoints

The ten final model checkpoints and intermediate checkpoints
are preserved in the accompanying Google Drive submission ZIP.
They are not duplicated in this GitHub folder.
